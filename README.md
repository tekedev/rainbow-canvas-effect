# Rainbow Canvas Effect — HTML5 Visual Canvas Animation

> **Creative Coding Project by Enes Teke (tekedev)**

---

## 🏛️ Executive Summary

**Rainbow Canvas Effect** is a lightweight creative coding script generating smooth, interactive rainbow gradient waves on HTML5 Canvas.

---

## ⚡ Key Features

- **60 FPS Animation Loop:** Uses `requestAnimationFrame` for silky-smooth motion.
- **Responsive Resizing:** Automatically scales to window dimensions.

---

## 🛠️ Tech Stack

- **Core:** JavaScript, HTML5 Canvas API
